# E-Commerce Sales Analysis Using SQL

## Project Overview

This project analyses e-commerce sales data using Microsoft SQL Server.
The purpose of the project is to identify sales trends, top-performing
products, customer behaviour, and revenue performance.

## Business Questions

The analysis answers the following questions:

1. What is the total revenue?
2. Which products generate the most revenue?
3. Which customers have spent the most?
4. What are the monthly sales trends?
5. Which product categories perform best?
6. What is the average order value?
7. Which regions generate the most revenue?

## Tools Used

- Microsoft SQL Server
